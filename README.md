## 핵심 전제 3가지

1. **측정계가 두 개다.** 중간 OCV #01~#07은 **충방전기 내부(팬 가동 중)**, 전용 PRVT OCV #01~#03은
   **별도 OCV 계측기**. → 두 계열의 지문을 **분리해서** 봐야 한다.
2. **`docv7 = PRVT1 − PRVT3` 에는 팬의 직접 경로가 없다.** 팬은 오직 이월(충전 중 온도차 →
   SEI·자기방전율 차이)로만 도달한다. → **팬 서명이 docv7에 있으면 진짜 물리적 차이이고,
   보정 대상이 아니라 공정 개선 대상이다.**
3. **현행 라벨(A/E)은 현행 판정 로직으로 만들어졌다 → 순환 논리.** 라벨 대비 성능은
   "정확도"가 아니라 "현행 로직과의 일치도"다. 비순환 평가는 **spike-in 회수 시험(I3)** 으로 한다.

## 진단의 최우선 질문

**자기방전을 이미 3번 재고 있다.**

| 지표 | 정의 | SOC | 구간 |
|---|---|---|---|
| S_A | OCV#02 − OCV#03 | 10 % | 고온에이징1 + 상온2 |
| S_B | OCV#04 − OCV#05 | 70 % | 고온에이징2 + 상온3 |
| S_C | PRVT#01 − PRVT#03 (= docv7) | 30 % | 상온5 + 상온6 |

> **세 지표가 셀 수준에서 서로 상관이 있는가?** (분석 ID `C1`)
> - **있다** → 자기방전은 셀 고유의 재현 특성. 현 판정은 실체를 보고 있고, 셋을 합치면 더 정확해진다.
> - **없다** → docv7은 대부분 구간 특이 잡음. 단일지표 판정 자체가 취약하다.
>
> 그리고 **S_A·S_B는 현행 라벨 생성에 쓰이지 않았다** → 현 E등급 셀이 S_A·S_B에서도
> 튀는지 보면 **분해 없이 순환 논리를 반쯤 깰 수 있다** (`C2`).

## 설치 · 실행

```bash
pip install -r requirements.txt

# 시각화 스타일 데모 (합성 데이터, 데이터 없이 실행 가능)
python -m tests.demo_style
# → reports/figures/demo/*.png
```

**실행 환경 제약**: Python 3.8 · 32bit · **scipy/sklearn 없음** → 통계·회귀·이상탐지를
전부 numpy로 직접 구현한다. 한글 폰트(Malgun Gothic)는 사용 가능 → **그림 라벨 전부 한글**.

### 시각화 규칙 요약 (`style.py` 가 강제)

- **제목 = 결론 문장**, **부제 = 이 그림 읽는 법** — `kind_fig()` 가 둘 다 요구
- **모든 전압 수치에 판정 기준(0.8 mV) 대비 % 병기** — 컬러바 이중 눈금 / `mv_text()`
- 발산형 컬러맵은 **0 중심 대칭 강제**, 무지개 금지, 색맹 안전
- 트레이 히트맵은 **행 A~L · 열 1~12** 라벨, 결측은 해칭, 팬 오버레이 옵션
- **p값 표기 금지** (N≈10만이라 전부 유의 → "유의=중요" 오독 유발). 효과 크기만.
