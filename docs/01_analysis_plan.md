# 파트 I — 현 상황 진단

## A. 데이터 신뢰성 (측정계 감사)

여기서 걸리면 이후 전부 무의미하다. **가장 먼저.**

| ID | 분석 | 방법 | 왜 |
|---|---|---|---|
| **A1** | **분해능(LSB) 실측** | 각 변수 값의 계단 간격 히스토그램·최소공배수 추정 | docv7 지문이 0.048 mV인데 LSB가 0.1 mV면 **반올림 아티팩트**. 유령 쫓기 방지 |
| **A2** | **결측 구조 맵** | 위치별·트레이별·시간순 결측률 | 미해결 "결측 밴드"의 정체 |
| **A3** | **불량 온도핀 색출** | stuck 값 / 로버스트 이상치 / 이웃 대비 고립 | 타 랏 2.84%. 온도 기반 분석 전부의 전제 |
| **A4** | **측정 노이즈 바닥** | PRVT #01/02/03 3점의 단기 반복성에서 추정 | **"0.048 mV가 노이즈보다 큰가"** — 모든 유의성 판단의 기준선 |
| **A5** | 중복·재측정 레코드 | 동일 셀 다중 행 탐지 | 데이터 오염 |
| **A6** | 단위·범위 검증 | mV/V 스케일, 물리적 범위 이탈 | 파이프라인 오류 |

## B. 정보 흐름 — 산포 예산 (Variance Budget)

**"선별이 쓰는 정보가 어느 공정에서 생기고 어느 공정에서 지워지는가"** 를 한 장으로.

| ID | 분석 | 내용 |
|---|---|---|
| **B1** | **산포 전개 곡선** | 공정 순서 축에 각 단계의 트레이 내 로버스트 산포(MAD)를 나열. 온도 산포도 겹침 |
| **B2** | **CV 종료 = 정보 리셋 지점 표시** | 정전압 종료 공정은 전압을 강제로 맞추므로 산포가 붕괴 → 그 이전 정보가 지워짐 |
| **B3** | **구배 생존 곡선 (persistence)** ★ | 단계 k의 셀별 위치 편차가 단계 k+1에 얼마나 남는가 = 셀 수준 상관의 사슬. "이 구배는 어디서 태어나 어디까지 살아남는가" |
| **B4** | **docv7 분산 귀속(waterfall)** | 최종 docv7 분산을 앞선 단계별 기여로 분해 |

> B3은 발표에서 매우 직관적이다. 구배가 OCV#02에서 생겨도 **뒤에서 지워지면 docv7과 무관**하다.
> 지금까지 아무도 "생존 여부"를 확인하지 않았다.

## C. 자기방전 3지표 삼각검증 ★★ — 진단의 최고 가치

셀마다 자기방전 지표가 **3개** 있다. 지금은 하나만 쓰고 있다.

| 지표 | 정의 | SOC | 구간 |
|---|---|---|---|
| **S_A** | OCV#02 − OCV#03 | 10 % | HT1(60°C) + RT2 |
| **S_B** | OCV#04 − OCV#05 | 70 % | HT2(60°C) + RT3 |
| **S_C** | PRVT#01 − PRVT#03 (= docv7) | 30 % | RT5 + RT6 (상온) |

| ID | 분석 | 판정 |
|---|---|---|
| **C1** | **셀 수준 상관행렬** (트레이 효과 제거 후) ★ | **r ≳ 0.2~0.3 → 자기방전은 셀 고유의 재현 특성. 현 판정은 실체를 보고 있고 3개 결합 시 SNR 개선.** **r ≈ 0 → docv7은 대부분 구간 특이 노이즈. 단일지표 판정 자체가 취약.** |
| **C2** | **순환 라벨 깨기** ★★ | 현 E등급은 S_C에서 만들어졌고 **S_A·S_B는 라벨 생성에 쓰이지 않았다.** E등급 셀이 S_A·S_B에서도 상위 꼬리인가? → **분해 없이 얻는 준독립 검증** |
| **C3** | **아레니우스 환산** | 각 구간을 시간·온도로 정규화 → 등가 누설(µV/day @25°C, nA). 세 지표가 같은 값을 가리키는가 |
| **C4** | **선별력 비교** | (상위 꼬리 두께)/(코어 산포). **HT 구간은 60°C 가속이라 불량 신호가 증폭 → S_A·S_B가 docv7보다 민감할 가능성** = 이미 측정 중인 **무료 선별 인자** 발굴 |
| **C5** | **PRVT 3점 이완/누설 분해** | 구간1(P1→P2)·구간2(P2→P3) 강하율 비교. 선형=누설(진짜 신호) / 감쇠=잔여 이완(nuisance). **각각의 공간 필드를 따로** |

> **C1 한 개의 숫자가 이후 모든 방향을 결정한다.** 최우선.

## D. 상관 구조 — 전 변수 관계 지도 (요청 항목)

| ID | 분석 | 내용 |
|---|---|---|
| **D1** | **단계 전압 × 온도 상관 히트맵** (요청) | 행 = 각 공정 온도(min/mean/max·자기발열), 열 = 각 단계 전압. 트레이별 공간 상관의 중앙값 |
| **D2** | **단계 전압/온도 × 타깃 상관** (요청) | 타깃 = PRVT#01/#02/#03, docv7, S_A, S_B. "무엇이 최종 판정값과 닮았는가" |
| **D3** | **within / between 분리** ★ 필수 | 트레이 **내** 상관과 트레이 **간** 상관을 반드시 분리. 섞으면 심슨의 역설 — 부호가 반대로 나올 수 있다. 기존 R²=0.058도 이 혼합의 산물일 수 있음 |
| **D4** | **실효 dU/dT 의 SOC 의존성** ★ | within-tray 온도–전압 기울기를 **SOC 단계별로** 추정 → 곡선화 |
| **D5** | **엔트로피 계수 지문 대조** ★★ | D4 곡선을 **문헌의 흑연/NCM 엔트로피 계수 곡선과 대조.** 부호·크기가 맞으면 **"전압 구배는 온도 기원"이 지문 대조로 증명**된다. 발표에서 매우 강력 |
| **D6** | 종료전압 → 다음 OCV 전파 | CV 종료 스텝 제외. 종료전압의 위치 편차가 다음 OCV에 얼마나 넘어가는가 |
| **D7** | **분극 프록시 = 공짜 저항계·전기화학 온도계** ★ | `P = V_end − 직후 OCV ≈ 내부저항 + 확산분극`. ① DCIR 없이 저항 프록시 ② **온도핀 2.84%가 불량인 상황에서 독립적 온도 대리 측정치** ③ 자기발열 rise와 교차검증 |

> **D7 검증 문장**: 저항 프록시 3종(분극 P · 자기발열 rise · 측정 온도)이 서로 일치하는가.
> 일치하면 온도 데이터를 신뢰해도 좋고, 어긋나면 어느 쪽이 고장인지 지목된다.

# 파트 II — 구배 원인

## E. 공간 지문 (12×12)

**중간 OCV 계열(충방전기)과 PRVT 계열(계측기)을 반드시 분리해서 본다.**

| ID | 분석 | 내용 |
|---|---|---|
| **E1** | 평균 필드 **+ RMS 필드 병기** ★ | 평균 필드만 보면 링/역링이 상쇄돼 효과를 과소평가. **RMS(부호 무관)를 반드시 같이.** 공통 지문 ±0.048 mV는 "위치 효과 크기"가 아니라 "부호가 일관된 몫"일 뿐 |
| **E2** | **위치별 Q10/Q50/Q90 + MAD 맵** ★★ | **분포 전체 평행이동 → nuisance(보정 가능). Q50 같은데 상위 꼬리만 두꺼움 → 진짜 불량 편중(보정 금지).** 보정 정당성의 결정적 시험 |
| **E3** | 테두리 거리 프로파일 | d=0~5 별 프로파일. **계단형 → 접촉/기구물 / 지수 감쇠 → 열전도 / 선형 → 기류** |
| **E4** | 코너 vs 테두리-중앙 | 2D 열확산이면 코너(2면 노출)가 약 2배. 같으면 열전도 기각 |
| **E5** | 이방성 (행 vs 열) | 등방 열확산 기각 검정 |
| **E6** | **공간 스펙트럼 (2D FFT)** ★ | 기존 지표(ring·Moran's I·2차 다항)는 **전부 저주파** → 팬 서명 같은 고주파 구조를 원리적으로 못 잡는다. 신규 필수 |
| **E7** | **PCA(EOF) 공간 모드** | 1035×144 → 상위 2~3개 모드 + **트레이별 부호 있는 점수**. **링/역링은 같은 모드의 부호 차이일 뿐** → 8가지 유형 분류 폐기 |
| **E8** | 분산 분해 | `위치고정 μ(pos)` / `트레이×위치` / `셀 잔차` 성분 비율 → **보정의 천장** |

## F. 팬 서명 검증 (실험 불필요)

| ID | 분석 | 판별 |
|---|---|---|
| **F1** | **행 프로파일** | 극대 ≈ 행 3/6/10 (팬 축), 극소 ≈ 행 4.5·8.3 및 **1·12**(배열 바깥) |
| **F2** | **밴드별 열 프로파일** ★★ **판결문** | 밴드1(1~4행)≈밴드3(9~12행) **≠** 밴드2(5~8행) → **팬 확정**. 셋 다 동일 → 팬 기각(분리형 = 배선·기구물) |
| **F3** | **진폭 ∝ 발열량** | 팬 상시 가동이어도 셀-공기 온도차 0이면 구배 0. 고전류 스텝에서 크고 무발열 구간에서 작아야 |
| **F4** | 팬 상대좌표 접기 | 13개 팬 중심 기준 반경 프로파일 → 충돌제트 형상. 팬 직경 확정 후 |

`00_facts.md §2`의 "중간 OCV = 충방전기 / PRVT = 별도 계측기" 사실이 만든 기회.

| ID | 분석 | 내용 |
|---|---|---|
| **G1** | **OCV#07 ↔ PRVT#01 교차검증** ★★ | **둘 다 SOC 30 %**, 사이에 RT4(1일)만 있음. 하나는 충방전기 내부, 하나는 별도 계측기. **차이 필드 = 충방전기 지문 − 계측기 지문 (+ 1일 자기방전).** 두 측정계를 분리하는 천연 실험 |

# 파트 III — 보정 필요성 · 설계

## I. 판정 영향 정량화 — "왜 고쳐야 하는가"

| ID | 분석 | 발표 가치 |
|---|---|---|
| **I1** | **판정 마진 % 단위계** ★ | 모든 수치를 **"판정 기준 0.8 mV의 몇 %"** 로 환산. 비전문가에게 필수 |
| **I2** | **위치별 불량 판정률 지도 + 기대 대비 배수** ★★ | "이 자리에 놓이면 다른 자리보다 **N배** 더 불량 판정된다." 클라이맥스 |
| **I3** | **위치별 검출력 시뮬레이션 (spike-in)** ★★ | 정상 셀에 인공 결함(+0.5/0.8/1.5 mV) 주입 → 위치별 검출률·오경보율. **"똑같은 불량 셀이 자리에 따라 잡히기도 놓치기도 한다"** — 가장 설득력 있는 슬라이드이자 **유일한 비순환 성능지표** |
| **I4** | 트레이 간 vs 트레이 내 산포 비교 | 트레이별 상대판정이 옳은 설계인지 검증 |
| **I5** | 과검/미검 규모 환산 | 셀 수/일 → 필요시 비용 |

## J. 보정 설계 (권고안)

| ID | 내용 |
|---|---|
| **J1** | **보정 레벨 = docv7.** PRVT 개별 보정 후 차분은 **금지** — ±3 mV 필드 2개를 추정해 ±0.05 mV를 만드는 것이라 오차 증폭(2% 오차만으로 신호 전체를 덮음). 공통모드는 셀 단위에서 **정확히** 상쇄되므로 **차분이 먼저, 추정이 나중** |
| **J2** | **ML 인자로 위치를 직접 주는 것 금지** — 모델이 "테두리=원래 높음"을 학습해 **테두리 진짜 불량을 조직적으로 미검**. 라벨이 순환이라 지표상으로는 오히려 좋아 보이는 **조용한 실패**. 대신 **보정된 잔차 + 보정량 ĝ**를 입력으로 |
| **J3** | 3층 구조: **L1** 셀별 공변량 회귀(위치 미사용) → **L2** 트레이별 저차 기저(PCA 모드 2~3개, 부호 있는 점수 → 링/역링 자동 처리) → **L3** 위치별 스케일 정규화 σ(pos) |
| **J4** | 적합 규칙: 정상 셀만 · **로버스트 손실** · **leave-one-cell-out** · 자유도 최소화(유연할수록 진짜 불량을 삼킴) |
| **J5** | 검증: **I3 spike-in 회수 시험.** 판정 기준은 **"검출력이 위치에 의존하지 않는가"** 하나 |
| **J6** | **보정하면 안 되는 것**: 팬 이월 성분은 진짜 물리적 차이(§00_facts 2) → 보정 대상이 아니라 **공정 개선 대상**. E2에서 "상위 꼬리만 두꺼움"으로 판명된 성분도 보존 |
