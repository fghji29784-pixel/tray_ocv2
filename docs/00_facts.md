### 1.1 공정 순서

```
LCI > RT1 > OCV1 > C1 > C2 > OCV2 > HT1 > RT2 > OCV3 > C3 > C4 > OCV4 > HT2 > RT3 > OCV5
    > C5 > C6 > C7 > OCV6 > D1..D7 > OCV7 > RT4 > PRVT1 > RT5 > PRVT2 > RT6 > PRVT3
```

- `C`=충전, `D`=방전, `RT`=상온 에이징, `HT`=고온 에이징(60°C), `LCI`=Low Current Inspection
- 연속(휴지 없는) 충전 블록: `{C1,C2}` / `{C3,C4}` / `{C5,C6,C7}` · 연속 방전 블록: `{D1…D7}`

### 1.2 각 OCV 측정 시점의 SOC

| 측정 | SOC | 비고 |
|---|---|---|
| OCV1 | ≈0% | 충전 전 |
| OCV2 / OCV3 | 10% | **HT1 전 / 후 — matched-SOC** |
| OCV4 / OCV5 | 70% | **HT2 전 / 후 — matched-SOC** |
| OCV6 | 100% | 만충 |
| OCV7 | 30% | 방전 후 |
| PRVT1 / 2 / 3 | 30% | 전용 OCV 3점 |

## 2. 측정계 — **두 개의 서로 다른 시스템** ★

| 측정 | 장소 | 상태 |
|---|---|---|
| **중간 OCV #01~#07** | **충방전기 내부 (in-situ)** — 팬 가동 중 | **확정** |
| **전용 PRVT OCV #01~#03** | **별도 OCV 계측기** — 충방전기 밖 | **확정** |

**이 분리가 분석 설계의 핵심이다.**

- 중간 OCV 계열에는 **충방전기(팬 기류)의 지문**이 찍힌다.
- PRVT 계열에는 **OCV 계측기(지그·프로브·채널·주변 열환경)의 지문**이 찍힌다.
- `docv7 = PRVT1 − PRVT3` 이므로 **팬은 docv7에 직접 각인되지 않는다.**
  팬 → docv7 경로는 오직 **이월**뿐:
  `충전 중 기류 불균일 → 위치별 셀 온도차 → SEI·자기방전율 차이 → docv7`
  → **팬 서명이 docv7에서 발견되면 측정 아티팩트가 아니라 진짜 물리적 차이이며,
    보정 대상이 아니라 공정 개선 대상이다.**

### 2.2 ★ 중간 OCV 온도가 여는 것

중간 OCV는 **팬이 돌아가는 충방전기 안에서 측정**되고, 이제 **그 순간의 셀 온도**가 있다.

1. **팬 기류장의 직접 측정.** 전압은 SOC·용량·dU/dT가 섞이지만 **온도는 순수한 열장**이다.
   → 팬 서명 검증(F 그룹)을 **전압이 아니라 온도로 직접** 수행할 수 있다. 훨씬 깨끗하다.
2. **팬 기류장을 7번 독립 측정한 셈** (OCV#01~#07). **7장의 온도 필드가 서로 재현되면
   그 자체가 팬 가설의 증거**이고, 평균하면 SNR이 √7 개선된다.
3. **dU/dT 실측 가능.** 같은 셀·같은 SOC에서 온도와 전압을 동시에 얻으므로,
   트레이 내 회귀로 **SOC 단계별 dU/dT를 데이터에서 직접** 뽑을 수 있다.
4. **온도 보정 잔차 OCV.** 각 단계 전압에서 온도 몫을 제거한 "순수 전기화학" 성분을 분리
   → **단계별로 "구배 중 온도 몫 vs 비온도 몫"을 정량화**할 수 있다.
5. **S_A·S_B의 오염 제거.** `S_A = OCV2 − OCV3` 은 두 측정 시점의 온도가 다르면
   `dU/dT × ΔT` 만큼 오염된다. 이제 보정 가능 → **순수 자기방전 지표**가 된다.

### 2.3 ★ 타임스탬프가 여는 것

1. **구간 실제 경과시간 확보.** 지금까지 "간격 ≈1일, ≈2일"은 **추정값**이었다.
   실측 Δt를 쓰면 자기방전 지표를 **mV → mV/day (율)** 로 환산할 수 있다.
2. **세 지표의 통일 비교 가능.** S_A·S_B·S_C는 구간 길이·온도가 전부 다르다.
   시간·온도 정규화(아레니우스) 후에야 **등가 누설전류로 같은 자에 놓고 비교**할 수 있다.
3. **라인 정체 = 숨은 판정 편향.** 트레이마다 에이징 실제 시간이 다르면 전압 강하량도
   비례해 달라진다. 트레이별 mode 판정이 일부 상쇄하지만 완전하지 않다.
   → **"에이징 시간 편차 → 판정 편차"** 는 지금까지 아무도 확인하지 않은 축이다.
4. **시계열 진단(H 그룹) 가능.** 트레이 처리 순서 축이 생긴다.
5. 셀별 타임스탬프까지 있으면 **트레이 내 측정 순서(스캔) 효과**도 검사 가능.

### 2.3b 데이터 요청 목록 (우선순위)

> **원칙: "모든 스텝의 시작/종료 시각"으로 한 번에 받는다.** 나중에 재요청하는 비용이
> 지금 한 번에 받는 비용보다 훨씬 크다.

| 순위 | 항목 | 왜 필요한가 | 상태 |
|---|---|---|---|
| **1** | **에이징 스텝(HT1·HT2·RT1~RT6) 시작/종료 시각** ★★ | 자기방전은 에이징 중에 일어난다. **60°C 자기방전은 25°C의 10~30배.** OCV 측정 시각만으로는 총 Δt만 알 뿐 **그중 몇 시간이 60°C였는지 모른다.** 총 Δt가 같아도 HT가 길었던 트레이는 자기방전이 훨씬 크다 → `K3`·`K5`가 이것 없이는 반쪽 | 요청 필요 |
| **2** | **충·방전 스텝 시작/종료 시각** ★ | ① **CV가 지운 정보 복원**(§2.3c) ② **위치별 냉각 시상수 τ**(`F6`) ③ 열 노출 적분 | 요청 필요 |
| 3 | OCV 측정 시각 | 구간 Δt, 율(mV/day) 환산 | **확보** |
| 4 | 중간 OCV 셀 온도 | 팬 기류장 직접 측정 | **확보** |

> ⚠️ **충방전 시각으로는 HT1을 가를 수 없다.** 공정 순서가 `OCV2 > HT1 > RT2 > OCV3` 라
> 그 사이에 충방전 스텝이 없다. **에이징 스텝 자체의 시각이 따로 필요하다.**

**같이 확인할 것**: 시각이 **셀 단위인가 트레이 단위인가.**
충전은 채널별로 돌므로 셀 단위일 가능성이 높고, 그렇다면 §2.3c의 저항·용량 프록시가
**셀별**로 생겨 가치가 훨씬 크다. 트레이 단위면 τ·열노출은 되지만 셀별 프록시는 불가.

### 2.3c ★ 스텝 소요시간이 여는 것

**(1) CV가 지운 정보를 시간이 복원한다**

| 스텝 종료 조건 | 종료전압 | 소요시간 |
|---|---|---|
| CC 종료 (시간 기준) | **정보 있음** | 고정 → 정보 없음 |
| **CV 종료 (전압 기준)** | 강제 → **정보 없음** | **정보 있음** ★ |

원칙: **고정된 쪽은 버리고 가변인 쪽을 취한다.** 두 변수는 상보적이다.
정전압 종료 스텝을 분석에서 제외했던 이유(전압 강제)가 **소요시간으로는 해소**된다.
또한 **CV 구간 길이는 셀의 저항·용량 상태를 직접 반영**한다(저항↑ → CV↑, 용량↑ → CC↑)
→ DCIR 컬럼 없이 저항 지표를 하나 더 얻는다 (`D7`의 분극 프록시와 상보).

**(2) 위치별 냉각 시상수 τ(pos)** — 팬 가설의 직접 측정
온도만으로는 "지금 몇 도"까지다. **온도 + 시간이 있어야 "얼마나 빨리 식는가"** 를 얻는다.
팬 가설의 직접 예측: **팬 축 아래는 τ가 짧고, 팬 사이·배열 바깥은 τ가 길다.**
온도 스냅샷 비교(`F2`)보다 한 단계 강한 증거 — "온도가 다르다"가 아니라
**"열이 빠져나가는 속도 자체가 위치마다 다르다"** 를 보인다.

**(3) 열 노출 적분** — 아레니우스 열 이력은 온도 × 시간. duration 없이는 적분 불가.

### 2.4 현재 적용 중인 가정 (⚠️ 잠정)

> **가정 A1**: OCV 계측기(장비)의 개체차·채널차는 **없다**고 본다.
> **가정 A2**: 트레이(캐리어) 개체차는 **없다**고 본다.
>
> 이 가정 하에서 **G 그룹(측정계 분리)·H4(트레이 재현성)는 보류**한다.
> 단 가정일 뿐이므로, 다른 원인으로 설명되지 않는 잔차가 남으면 **가장 먼저 되살릴 후보**다.
> 특히 `docv7`은 전적으로 PRVT 계열에서 나오므로, 계측기 가정이 틀리면 결론이 바뀐다.

### 3.1 팬 중심 좌표 (셀 격자 기준, 도면 픽셀 판독 — CAD 검증 필요)

| 밴드 | 행 중심 | 열 중심 | 열 피치 |
|---|---|---|---|
| 상단 (4개) | **2.6** | 1.9 / 5.2 / 8.5 / 11.5 | **3.2 셀** |

## 4. 판정 로직 (현행)

```
docv7 = PRVT1 − PRVT3   (또는 Delta OCV #07 컬럼)
트레이별 docv7 의 mode 산출 → (셀 docv7 − tray mode) > 0.8 mV → 불량(E)
```

- **★Label(A=양품/E=불량)은 이 로직으로 만들어진 것 → 순환 논리.**
  라벨 대비 성능은 "진짜 정확도"가 아니라 "현행 로직과의 일치도"일 뿐이다.
- mode는 값 양자화 때문에 불안정 (타 랏에서 표본 소폭 변경만으로 판정 16셀 뒤집힘 실측).

> 평가된 적이 없다.** 재평가 필요.
