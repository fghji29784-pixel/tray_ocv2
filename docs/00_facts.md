## 1. 제품 · 공정

| 항목 | 값 | 상태 |
|---|---|---|
| 셀 형태 | 원통형(cylindrical) | 확정 |
| 트레이 | **12행 × 12열 = 144셀**. Cell No 1~144 = A01~L12 | 확정 |
| 랏 규모 | 약 703~1035 트레이 / 랏 (랏별 상이) | 확정 |

### 1.1 공정 순서

```
LCI > RT1 > OCV1 > C1 > C2 > OCV2 > HT1 > RT2 > OCV3 > C3 > C4 > OCV4 > HT2 > RT3 > OCV5
    > C5 > C6 > C7 > OCV6 > D1..D7 > OCV7 > RT4 > PRVT1 > RT5 > PRVT2 > RT6 > PRVT3
```

- `C`=충전, `D`=방전, `RT`=상온 에이징, `HT`=고온 에이징(60°C), `LCI`=Low Current Inspection
- 연속(휴지 없는) 충전 블록: `{C1,C2}` / `{C3,C4}` / `{C5,C6,C7}` · 연속 방전 블록: `{D1…D7}`

### 1.2 각 OCV 측정 시점의 SOC

| 측정 | SOC | 비고 |
|---|---|---|
| OCV1 | ≈0% | 충전 전 |
| OCV2 / OCV3 | 10% | **HT1 전 / 후 — matched-SOC** |
| OCV4 / OCV5 | 70% | **HT2 전 / 후 — matched-SOC** |
| OCV6 | 100% | 만충 |
| OCV7 | 30% | 방전 후 |
| PRVT1 / 2 / 3 | 30% | 전용 OCV 3점 |

## 2. 측정계 — **두 개의 서로 다른 시스템** ★

| 측정 | 장소 | 상태 |
|---|---|---|
| **중간 OCV #01~#07** | **충방전기 내부 (in-situ)** — 팬 가동 중 | **확정** |
| **전용 PRVT OCV #01~#03** | **별도 OCV 계측기** — 충방전기 밖 | **확정** |

**이 분리가 분석 설계의 핵심이다.**

- 중간 OCV 계열에는 **충방전기(팬 기류)의 지문**이 찍힌다.
- PRVT 계열에는 **OCV 계측기(지그·프로브·채널·주변 열환경)의 지문**이 찍힌다.
- `docv7 = PRVT1 − PRVT3` 이므로 **팬은 docv7에 직접 각인되지 않는다.**
  팬 → docv7 경로는 오직 **이월**뿐:
  `충전 중 기류 불균일 → 위치별 셀 온도차 → SEI·자기방전율 차이 → docv7`
  → **팬 서명이 docv7에서 발견되면 측정 아티팩트가 아니라 진짜 물리적 차이이며,
    보정 대상이 아니라 공정 개선 대상이다.**

### 2.1 미확인 (확인 필요)

| # | 질문 | 왜 중요한가 |
|---|---|---|
| Q1 | OCV 계측기는 **트레이째 일괄 측정**인가 **셀별 스캔**인가? | 스캔이면 순서×드리프트가 공간 패턴이 됨 |
| Q2 | OCV 계측기는 **몇 대**인가? | 계측기별 지문 분리 가능 여부 |
| Q3 | 충방전기 → 계측기 이동 시 **셀의 트레이 내 위치가 보존**되는가? | 두 지문을 같은 좌표계에서 비교 가능한지 |
| Q4 | **중간 OCV에 온도 컬럼이 있는가?** | 있으면 충방전기 내부 온도 = 팬 기류의 직접 측정치 (가치 매우 큼) |
| Q5 | 측정 **타임스탬프**(스텝 시작/종료)가 있는가? | 스캔 순서·라인 정체·시계열 진단 |
| Q6 | 트레이 ID가 **랏을 넘어 재사용**되는가? | 캐리어 하드웨어 원인 판별(실험 없이) |

## 3. 충방전기 설비

| 항목 | 값 | 상태 |
|---|---|---|
| 충방전기 1대당 트레이 | **1장 (144셀)** | 확정 |
| 냉각팬 | **4 − 5 − 4 = 13개, 3밴드 엇배열(staggered)** | 확정 |
| 팬 가동 | **상시 가동** | 확정 |
| 라인 내 호기별 팬 배열 | **전 호기 동일** | 확정 |
| 팬 직경 | **미확정 (보류)** | 미확인 |

### 3.1 팬 중심 좌표 (셀 격자 기준, 도면 픽셀 판독 — CAD 검증 필요)

| 밴드 | 행 중심 | 열 중심 | 열 피치 |
|---|---|---|---|
| 상단 (4개) | **2.6** | 1.9 / 5.2 / 8.5 / 11.5 | **3.2 셀** |
| 중앙 (5개) | **6.4** | 2.0 / 4.3 / 6.6 / 8.9 / 11.2 | **2.3 셀** |
| 하단 (4개) | **10.2** | 1.9 / 5.1 / 8.4 / 11.4 | **3.2 셀** |

- 행 방향 팬 피치 ≈ **3.8 셀**
- **열 피치가 밴드마다 다르다(3.2 / 2.3 / 3.2) = 비분리형(non-separable) 서명.**
  배선 하네스·MUX 뱅크·트레이 리브 등 경쟁 가설은 전부 분리형이라 이 서명을 만들 수 없다.
- **1행·12행이 팬 배열 세로 방향 바깥**에 놓인다 → "테두리 高" 링이 기하만으로 설명될 수 있다.

## 4. 판정 로직 (현행)

```
docv7 = PRVT1 − PRVT3   (또는 Delta OCV #07 컬럼)
트레이별 docv7 의 mode 산출 → (셀 docv7 − tray mode) > 0.8 mV → 불량(E)
```

- **★Label(A=양품/E=불량)은 이 로직으로 만들어진 것 → 순환 논리.**
  라벨 대비 성능은 "진짜 정확도"가 아니라 "현행 로직과의 일치도"일 뿐이다.
- mode는 값 양자화 때문에 불안정 (타 랏에서 표본 소폭 변경만으로 판정 16셀 뒤집힘 실측).

## 5. 기존 랏(N32S D29) 실측 참고값

| 항목 | 값 |
|---|---|
| ΔOCV(=OCV1−OCV3) median / mode | 1.36 / 1.28 mV |
| 판정 임계 (mode+0.8) | ≈ 2.08 mV |
| 불량률 | ≈ 0.09 % (93/99,293셀) |
| docv7 공통 지문 진폭 | **± 0.048 mV** (전 트레이 평균 필드) |
| 트레이별 docv7 위치편차 p2p | **median 0.286 mV** = 판정 오프셋 0.8 mV의 **36 %** |
| 불량 온도핀 비율 | ≈ 2.84 % (트레이당 ~4개) |
| 온도가 ΔOCV를 설명하는 비율 | R² ≤ 0.094 (전용OCV 측정시점 온도 기준) |

> **주의**: 마지막 항목은 **전용OCV 측정시점 온도**로 계산한 것이다. 중간 OCV가 팬 가동 중
> 충방전기 내부에서 측정된다는 사실이 확인된 지금, **중간 OCV 단계의 온도 경로는 아직
> 평가된 적이 없다.** 재평가 필요.
