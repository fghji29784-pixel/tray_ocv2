- **V1a/V1b**: 전압 강하량 차이의 **38.3%가 자리 탓**, 현 판정은 이를 하나도 보정 안 함.
  (단 30.5%는 PCA 모드 3개 선택에 의존 — 각 모드 설명력 13.5/11.6/8.0%, 스크리 검증 여지)
- **V2 재현성**: 1,035 트레이를 무작위 반분(517 vs 518)해도 공통 지문 **r=0.977**, 위치 셔플 null 대조는 r≈0. → 랏 1개 한계를 방어하는 최강 증거. **단 분할 1회(seed 고정)라 반복검증 권장**.
- **V14 패턴유형**: 역링 48.5% · 링 36.4% · 무구조 15.1% — 무늬가 한 종류가 아니라 **정반대가 공존**.
- **V15 고정보정 한계**: 고정 7.8% vs 적응형 38.3% = **약 5배** → 트레이별 적응형/ML 보정이 필요한 정량 근거.

### 3단계 — 판정이 실제로 흔들린다 (I 그룹, V3/V16)

- **V3b spike-in(비순환 핵심 증거)**: 똑같은 0.8mV 인공불량인데 테두리거리별 검출률 **68.7%(d0) → 28.3%(d4), 최대 2.4배** 차. 원리 = `(원래 편차)+0.8 > 0.8` 이라, 원래 자기 트레이 mode보다 높던 자리(가장자리)는 쉽게 걸리고 낮던 자리(중앙)는 놓침. **판정 기준이 자리를 구분 안 하는 고정값이라 생기는 구조적 문제.** (d4·d5 표본 n=106·21로 작아 재확인 권장)
- **V3c 민감도**: 0.5mV는 어디서든 미검, 1.5mV는 어디서든 검출, **딱 0.8mV 근처(현 기준)에서만 자리 차이가 드러남**.
- **V16 위치별 불량률**: 최악 자리 **B3가 평균 대비 6.0배**. 단 overall 불량률 0.064%(위치당 기대 <1개)라 소수사건 가능성 — 전 위치 n=1035로 표본 자체는 충분.

### 4단계 — 확인했으나 영향 없음 / 미확정 (정직성, V5/V6/V7)

- **V5 시간편향(영향 없음)**: 에이징 실경과 vs 트레이 불량률 r=−0.05, 트레이간 시간차 72.3~77.3h(7% 이내). 이 랏은 애초에 시간편향이 생길 수 없는 조건.
- **V6 자기방전 3지표(전제 붕괴)**: 직전 휴지 S_A=0h·S_B=0h·S_C=24.2h / 강하량 S_A≈287·S_B≈46·S_C≈1.36mV(중앙값 기준 부호). ★**S_A·S_B는 휴지 0h = 이완 지배, 자기방전 아님**(오류1 실측 확정). 즉 실질 자기방전 지표는 S_C(=docv7) 하나뿐.
- **V7 팬 예측(판정 불가)**: 도면 예측 냉각열(상단 B/E/H/L, 중앙 B/D/G/I/K)이 실제로 더 차갑지 않음 — **3/3 밴드 전부 예측 불일치**(colder_as_predicted 모두 False). F4 이방성도 세로축 trend +0.54 / 가로축 −0.47로 부호 반대라 팬 확정/기각 모두 불가.
- **V4a/b 온도 배경(영향 있음, 판정직결은 미확정)**: 발열량 vs 자리별 온도불균일 **r=0.70, slope 0.104**(14개 공정단계). 저발열 discharge6(0.7°C)은 평평, 고발열 discharge1(8.8°C)은 중앙 고온 로브 뚜렷. → "발열이 크면 자리별 온도차 커진다"는 탄탄. 단 그 온도차가 docv7까지 직결된다는 증거는 S3에서 약함(R²≈0).

### 5단계 — 자기방전 신호 자체는 진짜 (V12/V13)
